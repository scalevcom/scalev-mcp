How it works

OAuth out front, Scalev API in charge.

The MCP Worker is a thin gateway. It validates the OAuth bearer is present and forwards it unchanged to the Scalev API. All authorization, scope enforcement, business selection, validation, and persistence stay in the Scalev API.

Claudedesktop, web, code
→
mcp.scalev.comCloudflare Worker
→
api.scalev.com /v3Scalev API authorization & logic

Nothing persists on the Worker

No tokens cached, no merchant data stored. The Worker is stateless.

Per-business explicit consent

Each tool call carries business_unique_id. No guesses across businesses.

Every call audited

Machine API logs in the Scalev API capture caller, scope, request, status, request_id.

Permissions

The scopes Claude will ask for.

Scopes are granted per business at consent time. You can revoke any grant from Scalev settings or claude.ai. Nothing is granted beyond what you approve.

Scope What it lets Claude do
page:list · page:readView your landing pages and inspect a single page.
page:createCreate new landing pages, including HTML Mode drafts.
page:updateEdit page metadata, publish, or unpublish a landing page.
page:deleteSoft-delete a landing page.
order:list · order:readView your orders and inspect a single order.
order:createCreate a new order on your behalf.
order:updateEdit order metadata, notes, or customer info.
order:change_statusMove an order through its status workflow.
order:create_awbCreate or cancel an AWB (airway bill) on an order.

Security & privacy

Built for review and built for production.

OAuth 2.1 + DCR

Claude registers dynamically (RFC 7591). PKCE S256 enforced. Refresh tokens rotate on every use.

Per-business scopes

Granular scopes (order:list, page:create, …) granted per business.

Audit log on every call

The Scalev API records caller, scope, request, status, and a correlatable request_id.

Disclosure-ready

Install

Five steps to wire Claude to Scalev.

Open Claude settings

Inside claude.ai, go to Settings › Connectors.

Add a connector

Choose Add custom connector while Scalev is awaiting directory approval.

Paste the URL

https://mcp.scalev.com/mcp

Sign in with Scalev

Select the business(es) you want Claude to access. Approve the scope list.

Use it in chat

Enable Scalev from the connectors menu and try one of the prompts above.

Get started

Connect Scalev to Claude in under a minute.
